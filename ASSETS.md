# Local asset sources

All travel images are downloaded from Unsplash using the curated photo IDs in [the asset script](scripts/fetch-assets.mjs). Images are used as illustrative photography for fictional stays and experiences.

- Lisbon Bica street: [Ivo Sousa Martins on Unsplash](https://unsplash.com/photos/a-streetcar-travels-down-a-lisbon-street-YEZy5Xk2Xs8).
- Mediterranean sailing: https://images.unsplash.com/photo-1540946485063-a40da27545f8
- Cinque Terre coast: https://images.unsplash.com/photo-1516483638261-f4dbaf036963
- Santorini: https://images.unsplash.com/photo-1613395877344-13d4a8e0d49e
- Bali: https://images.unsplash.com/photo-1537996194471-e657df975ab4
- Paris: https://images.unsplash.com/photo-1502602898657-3e91760cbb34
- Marrakech: https://images.unsplash.com/photo-1597212618440-806262de4f6b

Fonts are locally served WOFF2 files from Google Fonts. Their SIL Open Font License files are included in public/fonts.

No remote requests are required by the running app.
